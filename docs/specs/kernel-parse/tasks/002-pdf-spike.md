## Verdict (filled in 2026-08-31)

- **Fixture provenance:** **hand-written minimal PDFs**, generated by a one-off Python-stdlib script (`/tmp/opencode/genpdf.py`, throwaway — essence preserved in the transcript below): 3 pages × Helvetica text, uncompressed objects, exact xref offsets, no timestamps/file-ids → **regeneration is byte-identical** (verified with `cmp` after a fresh rerun). `with-outline.pdf` = 2,542 B (`sha256 1b26f694…99f0ea4`), `no-outline.pdf` = 1,950 B (`sha256 b53d6984…903d3ab`). Outline tree: root → Chapter One (p1) → Chapter Two (p2, child "A Folded Cloak" p2) → Chapter Three (p3); dest arrays `[<pageref> /Fit]`. Info dict carries `/Title (The North Wind and the Sun) /Author (Aesop)`. Cross-validated with poppler (`pdftotext`/`pdfinfo`) before the Rust spike.
- **`pdf-extract` @ 0.12.0:** **go.** `extract_text_from_mem_by_pages(&[u8]) -> Result<Vec<String>, OutputError>` is exactly the pure-core API T10 needs (bytes-in, per-page out; also `extract_text_from_mem` whole-doc). Extracted text is faithful: each page yields its laid-out lines joined by `\n`, with a `\n\n` prefix as the page marker (e.g. page 1 = `"\n\nChapter One\nThe North Wind and the Sun were disputing which was the\n…"`). No truncation, no glyph soup on unembedded base fonts; line wrapping is layout-derived, so paragraph assembly in T10 is a join/split concern for `clean.rs` (M4) — same class of work as TXT.
- **`lopdf` @ 0.44.0:** **go.** `Document::load` + `doc.get_toc() -> Toc { toc: Vec<TocType { level, title, page }>, errors }` does the whole ADR-0008 tier-1 walk in one call: sibling chains, nested children (child came back at `level: 2`), destinations resolved to 1-based page numbers. Missing `/Outlines` → `Err(DictKey("Outlines"))` — a clean signal for the single-chapter fallback. Info dict reads via `trailer["Info"]` → `as_dict()` → `as_str()`. One note for T10: `pdf-extract` 0.12 itself depends on `lopdf` 0.42 (and re-exports it as `pdf_extract::lopdf`); a direct `lopdf` dep adds a second copy — either pin `=0.42`-family or use the re-export so `get_toc` and text extraction share one lopdf.
- **Decision:** **GO — no swap.** Both crates usable, MIT, pure-Rust. T10 starts from: `pdf-extract` per-page text + `lopdf get_toc()` boundaries (top-level entries; `level > 1` handling is T10's flatten-vs-ignore call) + Info-dict metadata; no-outline ⇒ single chapter.
